# 이촌동와인가게 이미지 자동화 — 1단계 설정 및 검수

이 기능은 현재 **개발 브랜치**에만 있으며 공개 홈페이지에는 반영되지 않았습니다.

## 사전 설정

1. Google Programmable Search Engine에서 이미지 검색이 가능한 검색 엔진을 생성하고 검색 엔진 ID(CX)를 확인합니다.
2. Google Cloud에서 Custom Search JSON API 사용 가능 여부 및 과금 정책을 확인하고 API 키를 발급합니다. 서비스 신규 이용 가능 여부는 Google 공식 안내를 확인해야 합니다.
3. GitHub 저장소 → Settings → Secrets and variables → Actions → New repository secret에서 아래 두 값을 설정합니다.
   - `GOOGLE_CSE_API_KEY`: API 키
   - `GOOGLE_CSE_CX`: 검색 엔진 ID
4. API 키는 이슈·PR·소스코드·채팅에 붙여넣지 않습니다.

## 실행 절차

1. 기능 브랜치를 검토하고 워크플로를 기본 브랜치에 반영합니다. GitHub의 수동 실행 버튼은 기본 브랜치에 워크플로가 등록되어야 정상적으로 표시됩니다.
2. Actions → **Prepare wine image candidates** → Run workflow
3. `product_name`에는 검색할 와인 이름, `product_id`에는 카탈로그의 고유 식별자를 입력합니다.
4. 자동 생성된 검수용 PR에서 이미지 후보와 `review.json`의 원본 출처를 확인합니다.
5. 라벨·생산자·제품 일치 여부와 상업적 사용 권한을 확인합니다.

## 제한사항

- 현재는 **단일 제품당 최대 5개 이미지 후보**만 검색합니다. 대량 일괄 입력 UI는 아직 없습니다.
- 누끼 결과는 자동으로 정확성을 보증하지 않습니다. 투명 PNG는 900 × 1200 픽셀입니다.
- `image-review/`의 결과물은 검수용입니다. 승인 후 제품 카탈로그와 연결하는 기능은 **미구현**입니다.
- 외부 사이트 이미지에는 사용 권한이 필요합니다. 공식 생산자/공급사 이미지를 우선 권장합니다.
- 기존 `index.html`과 공개 제품 이미지는 변경하지 않습니다.
- 외부 검색 API의 가용성, 요금, 호출 한도는 실제 계정 설정 후 확인해야 합니다.

## 첫 시험 권장

제품명: `Sabio del Terruno Sauvignon Blanc`

정확한 라벨 및 제품을 확인할 수 있는 기준 이미지와 후보를 비교합니다. 검색 실패·이미지 다운로드 제한·배경 제거 오류가 발생하면 워크플로 로그에서 원인을 확인하고 수정합니다.
